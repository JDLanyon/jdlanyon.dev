# Slime Arcade - IGB400 University Project

**Slime Arcade** is a slime pet simulator game developed for **IGB400** at QUT using the Godot engine. Players interact with and care for a virtual slime companion in an arcade-style environment.

## Gameplay

- **Pet Simulation** - Care for your slime by feeding, playing, and keeping it happy
- **Arcade Interactions** - Mini-games and activities to engage with your slime companion
- **Responsive AI** - The slime reacts to player actions with animated behaviour states
- **Godot Engine** - Built using Godot's scene system and GDScript for game logic

## Development Context

Created as part of IGB400 - a game development unit focused on practical game design and implementation. The project demonstrates proficiency with the Godot engine, including scene management, signal-based communication, animation trees, and state machine patterns for AI behaviour.

## Built With

- **Godot Engine** - Open-source game engine with integrated 2D/3D support
- **GDScript** - Python-like scripting language for game logic
- **Animation Tree** - State-machine driven animation system for the slime companion
